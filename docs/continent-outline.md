# 现世大陆轮廓接入

## 第一阶段（2026-10-03）

默认游戏现在使用 `Continent::make_present()`：海陆轮廓来自
`runtime/assets/unused/textures/continent-present.png` 对应的 `docs/map/continent-present.svg`。
主大陆、南部海湾和东侧群岛已经成为地形数据，陆地可以行走，海面阻挡步行。

第一阶段只提取海陆。陆地暂时统一为平原；森林、山地、荒原、湖泊、河流、
势力边界和高度起伏尚未接入。图片中的河流细线和海岸装饰描边不参与碰撞。
城池仍为实际尺寸的体块建筑，进入城池不切换视角或比例。

## 坐标与采样

| 项目 | 当前值 |
|---|---|
| SVG 画布 | 2400×1600，左上角为原点 |
| PNG 尺寸 | 7500×5000；仅作为布局素材，不决定世界尺寸 |
| 世界范围 | 6144×4096 米，保持 3:2 |
| 地形格 | 384×256，每格 16 米 |
| 世界原点 | X = −3200、Z = −2688 米 |
| 方向 | 图右为 +X，图下为 +Z，北为 −Z |
| 换算 | X = −3200 + SVG横坐标×2.56；Z = −2688 + SVG纵坐标×2.56 |

城门选在原图的 (1250,1050)，对应世界 (0,0)，位于南部海湾北侧。
城池仍为 320×384 米，村庄为 128×80 米。比例尺是本次行走原型的选择，尚非最终世界规模。

离线导出器读取 SVG 的 `landshape`，只接受项目使用的闭合绝对 M/L/Z 多边形。
按格子中心采样后，把每行连续陆地记录为“行号、起始列、结束列（不含）”，
没有记录的格子为海域。33 个原始轮廓均有陆地格，合计 44,103 格、543 段。
岸线精度为 16 米，细小岬角可能断开为独立格子；显示与碰撞共用这份采样结果。

## 从城门走到海岸

```text
长风城 (0,0) ──城南大道，宽8米── 南田村 (0,112)
                                      │
                                南湾小径，宽4米
                                      │
                                南湾海岸 (0,240)
```

运行 `make run`，玩家出生于 (0,32)，保留城门外的材质展示区。
游戏内三个地点名称分别显示为 `Longwind City`、`Southfield Village`、`South Bay Coast`，
界面和日志使用英文；本文保留中文说明。
沿道路向南穿过村庄可以到海湾，沿 X=0 继续走会在 Z≈271.7 米处停住，
这包含角色半宽 0.3 米。群岛已经生成，可以用解锁镜头观察；当前没有渡海方式。
WASD、Shift、滚轮、Y、空格和 M 的操作保持原有行为。

原来的五类地形、六类地点小样例仍由 `make_prototype()` 提供给回归测试。
两张地图通过 `src/game/continent/layout.cpp` 共用城池和村庄的建筑布局。
当前游戏的地点为城池、村庄和海岸，旧样例的港口、要塞等尚未迁移到新大陆。

## 生成与检查

```bash
python3 docs/map/export_continent.py
python3 docs/map/export_continent.py --check
python3 docs/map/export_continent.py --preview build/linux-x86_64/Debug/artifacts/continent-outline.svg
```

导出器仅依赖 Python 标准库，输出为已提交的
`src/game/continent/land.generated.hpp`，包含源 SVG 的 SHA256。
普通构建和运行直接使用该数据，不需要 Python、SVG 解析库或原图文件。
修改 SVG 轮廓后应重新导出，`--check` 可以发现源图或导出结果过期。
预览图用白线叠加原始海岸，用黄色标记出生点，便于核对方向和地点尺度。

## 性能与验证

地面沿地形格和局部铺装边界生成，不再对整幅大陆每 4 米细分。
每个显示区块包含 16×16 格，即 256×256 米；本图共 384 个区块。
当前仍一次性加载全部区块，没有异步流式加载或远景层次。先通过合并网格控制
绘制项、模型 UBO 和 BLAS 的数量；扩大规模或增加密集场景前需要继续实现流式加载。

地形碰撞缓存每格是否阻挡，并只检查身体及移动扫掠范围附近的格子。
候选范围多包含一圈邻格，避免世界坐标换算的浮点舍入漏掉贴边碰撞。
窄阶段仍使用原来的连续扫掠和滑动；建筑数量较少，暂时继续遍历建筑碰撞体。

`world_map` 测试检查原图地标、群岛、海湾、海陆比例、地点落地、城池尺度、
城门双向通行、道路净空和海岸高速阻挡。`continent` 增加随机对照：
把阻挡格子展开为完整建筑碰撞体，与局部格子查询比较身体重叠和长距离滑动结果。

```bash
cmake --build --preset linux-x86_64-debug -j 8
ctest --test-dir build/linux-x86_64/Debug --output-on-failure
```
