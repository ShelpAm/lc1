# 光照

当前使用 metallic-roughness PBR 直接光照：GGX 法线分布、Smith-GGX 遮蔽项、Schlick Fresnel
及 Lambert 漫反射。底色为 sRGB 贴图解码后的线性颜色乘材质 factor、顶点颜色；顶点颜色只表达材质色。

每个 MSAA 采样点计算材质与直接光，阴影可见度仍按像素计算：

```text
L = 从表面指向光源的单位向量
V = 从表面指向相机的单位向量
N = 世界空间单位法线
H = normalize(L + V)
alpha = max(roughness, 0.045)²
F0 = lerp(0.04, base_color, metallic)
diffuse = (1 - F) * (1 - metallic) * base_color / pi
specular = D * G * F / (4 * NdotV * NdotL)
color = emissive
      + ddgi_irradiance * base_color * (1 - metallic) / pi
      + Σ visibility * radiance * (diffuse + specular) * NdotL
```

背光、视线处于表面背侧或半程向量退化时，直接光 BRDF 为零。`sample_light` 已计算点光源的距离衰减和
聚光灯的锥角衰减，这些权重只应用一次。主通道保留最多 4× sample shading，按实际 HDR 和深度格式
选择支持的采样数。主场景通过局部 DDGI 提供漫反射间接光，未启用 DDGI 的场景没有固定环境补光。
当前没有镜面 IBL，金属不接收 DDGI 漫反射。

`scene::PbrParameters` 保存线性参数，`scene::PbrMaterial` 另带非拥有的 CPU 图像引用。
游戏持有 `MaterialInfo`（参数及 GPU 纹理/采样器借用），`DrawItem::material` 指向它。
多个物体可共享并修改同一份 CPU 材质，不再创建 `GpuMaterial`，也没有独立材质 descriptor pool
或 64 个存活材质的限制。参数使用 glTF 默认值；程序生成的普通表面显式设 metallic = 0、
roughness = 0.8。

`Renderer::record()` 在验证输入后，将材质参数及 heap 索引复制到当前 `FrameResources`。
每个 draw 各有 object、material、frame UBO，后者保存该 draw 的资源索引；不会在录制下一次
draw 时覆盖前一次 draw 的数据。camera/lights 在同一帧槽内共享。CPU 参数只需活到 record
返回，mesh、纹理和采样器则必须活到对应 GPU 工作完成。

主材质通道使用原生 descriptor heap。每个帧槽持有自己的 heap；buffer 描述符在创建时分配，
纹理/采样器槽位首次使用时分配，后续在等待该槽 fence 后原位写入。因此改变参数、换纹理或
resize 不持续消耗新槽位，也不修改其他在途帧的描述符。buffer 的重复查询通过每个帧槽自己的 `DescriptorHeapCache`；会原位重写的 image 槽位
直接持有索引，不与缓存的资源身份混用。帧容量仍由 `make_frame_resources` 指定，
超限在上传前明确失败，不自动扩容。

阴影、时间累积、空间滤波和 tone mapping 也都使用 native descriptor heap。
`PassData` 将各通道所需的资源索引作为 push data 记录，每个 draw 的 object 索引独立。
相机、灯光与物体 buffer 在 ray-query 准备阶段上传一次，随后主材质通道复用；不能在提交前
清除阴影接收面 ID 或覆盖其他通道要读取的数据。各通道使用 shader object，不创建 graphics
pipeline、pipeline layout 或 descriptor set layout/pool。ImGui 按显式约定继续使用官方 Vulkan
后端，其内部 pipeline 和 descriptor set 是例外。主片元 shader 通过实际读取 `SV_SampleIndex`
并在该采样点插值 UV 保持完整 sample shading；实现及验证见 [shader object](shader-objects.md)。

已采样底色、metallic-roughness 和 emissive；MR 的 G 是粗糙度，B 是金属度，分别乘 factor。
底色和 emissive 使用 `TextureColorSpace::Srgb`，MR 使用 `Linear`，错误的色彩空间在绘制前验证时报错。
缺少上述贴图时绑定白色替代纹理，因此常量 factor 同样有效。
normal 贴图已接入，必须使用 `TextureColorSpace::Linear`；`normal_scale` 缩放切线空间 XY 分量。
材质 UBO 的 `flags` bit 0 表示贴图存在。没有贴图或强度为零时直接用网格法线，不采样默认法线纹理。
occlusion 仍待 IBL 接入，非空贴图目前明确报未支持。
普通 PBR 材质仍按不透明单面绘制，alpha 不开启混合；参与投影的几何仍视为不透明遮挡物。
透明火焰与火星走独立粒子路径，不将普通材质或 glTF alphaMode 自动转换为透明材质。

颜色先写入各帧槽的 RGBA16F 附件，在 HDR 空间完成 MSAA resolve，再用单采样全屏通道执行
`mapped = (color * exposure) / (1 + color * exposure)`。渲染器曝光默认 1，主游戏初始曝光为 2，必须有限且大于零。
输出到 sRGB attachment 时由硬件编码；UNORM 显示输出显式传 `OutputEncoding::Srgb`，
线性离屏输出使用默认 `Linear`，避免二次 gamma。超出 half-float 范围的亮度饱和到 65504。

程序生成的箱体各面拥有独立法线；地面和道路法线朝上。OBJ 保留自带法线，没有法线时使用三角形面法线。顶点法线通过模型矩阵的逆转置变换到世界空间，并在片元阶段重新归一化，因此支持非均匀缩放和镜像变换。零缩放等不可逆模型矩阵会在上传前报错。

## 切线与法线贴图

`Vertex::tangent` 的 xyz 是物体空间切线，w 是副切线手性（+1 或 -1）；默认全零表示没有切线。
`generate_tangents(vertices, indices)` 使用 Conan 的 `mikktspace/cci.20200325` 生成 UV0 切线，
按每个三角形角点的结果重新索引，因此会拆开 UV 镜像接缝，不能用旧索引覆盖不同切线。
`Model::generate_tangents()` 是当前 CPU 几何的便捷入口，在交给 `GpuModel` 或构造 `GpuMesh` 之前调用。
不使用法线贴图的网格不需要执行这一步。

生成过程拒绝退化 UV、退化三角形、非法索引和非有限数据，失败时保留原网格。
对于已经烘焙好的法线图，应在非均匀导入修正之前准备匹配的切线；已有的切线会随模型修正变换、
正交化，并在镜像时翻转 w。绘制使用法线贴图却没有有效切线的网格时，会在 Vulkan 绘制之前报错。

顶点阶段用模型矩阵的线性部分变换切线，用逆转置变换法线，并将模型的镜像符号乘入切线手性。
片元阶段重新正交化 T、归一化 N，按 `B = cross(N, T) * sign` 构造副切线，再把采样法线转换到世界空间。
法线图采用切线空间 +Y 约定；Vulkan viewport 的 Y 翻转不需要额外翻转法线图的绿色通道。
阴影射线偏移、时间历史和空间滤波继续使用未扰动的表面法线；背向该表面的光不会因法线图而漏光。
这不改变轮廓、碰撞或实际几何高度。

## 球形面积光与阴影

`SphereLight` 用 `position` 表示球心，`radius` 表示半径，`shadow_sample_count` 控制阴影采样数。
它与点光源一样，以中心位置计算方向和距离平方反比衰减，没有距离截断；遮挡则在朝向着色点的光源圆盘上采样多个位置，
把未遮挡射线的比例作为 `visibility`。半径为零退化为点光硬阴影。
这是面积光阴影近似，PBR BRDF 仍以球心方向求值，不能表现光源面积对高光的完整影响。

方向光、点光和聚光灯也投射 ray query 硬阴影。每个像素的光源可见度先进行时间累积，再供主通道读取。默认每帧 1 条射线、最多 32 帧历史；
材质、高光和
光照衰减仍按 MSAA 采样点计算，但阴影射线数量不随 MSAA 倍增。
采样、缓冲布局和已知限制见 [Ray query 阴影](ray-query-shadows.md)。

## Native heap 的字段读取约定

heap `ConstantBuffer` 中的矩阵与 `Light` 都**逐字段读取**，不整块传给 `mul` 或函数：
矩阵按 GLM 存储的列逐列读取后求线性组合（镜像手性用三列混合积），灯光逐字段读进局部
`Light` 再传给 `sample_light`。这不是风格偏好，而是绕开两个外部缺陷——NVIDIA 驱动对整块
矩阵加载的处理，以及 Slang 对 heap 嵌套数组的寻址。现象、触发形状、最小复现、外部链接与
复测方法见[外部缺陷记录](external-defects.md)第 1、2 条；`shaders/text.slang` 用四个
`float4` push constant 传矩阵，因此不经过这两条路径。

PBR GPU 测试覆盖投影、物体平移、逆转置法线、镜像/非均匀缩放、镜像 UV，以及不同光源。
保留这些数值检查；升级 Slang 或改变 heap 读取写法时需重新运行，不能只检查编译成功。

各阶段的实机结果与未验证范围见[历史验证记录](history/lighting-validation.md)。

## DDGI 漫反射间接光

`scene::Scene::set_diffuse_gi()` 可选启用局部探针体积，传入世界中心和线性天空辐亮度；
默认关闭，因此独立材质测试和没有环境设置的场景仍可验证纯直接光。
主场景以玩家脚底上方 6 米为中心，天空辐亮度随太阳高度变化，夜间与禁用太阳的 F4 模式为零。
主场景当前只启用天空和灯光的间接光，优先验证太阳直射、反弹与遮挡；材质自发光仍显示自身亮度，
默认不照亮周围。`DiffuseGi::emissive_lighting` 仅供显式启用自发光积分，已有 LED 专项测试保留。
天空背景暂时仍独立使用固定颜色。

`Ddgi` 复用阴影 TLAS，以实例 custom index 查询当帧 geometry 表，通过 GPU 地址读取网格
索引、顶点色、法线与 UV，再使用同一份材质 heap 数据读取底色、金属度和自发光纹理。
命中点计算有遮挡的 Lambert 漫反射直接光；未命中采样天空。
自发光三角形使用下述显式积分，不再依靠球面射线偶然命中，也不在命中点重复计入自发光。
这是一次漫反射反弹，不递归采样探针；间接采样不包含法线贴图或镜面反射。
球形光在该采样阶段使用光心硬阴影，主直接光仍使用原有软阴影。

采用四级嵌套探针体积，每级 16×8×16 个探针；中心按该级间距对齐并分别滚动。

| 层级 | 间距 | 水平覆盖 | 垂直覆盖 | 每帧更新探针 | 完整轮换 |
|---|---:|---:|---:|---:|---:|
| 近级 | 4 米 | 60 米 | 28 米 | 64 | 32 帧 |
| 中级 | 16 米 | 240 米 | 112 米 | 32 | 64 帧 |
| 远级 | 64 米 | 960 米 | 448 米 | 16 | 128 帧 |
| 最远级 | 256 米 | 3840 米 | 1792 米 | 16 | 128 帧 |

每探针 64 条旋转 Fibonacci 球面射线，方向每帧在 CPU 生成一次，由所有层级共享。
稳定帧总计更新 128 个探针、8192 条主射线，命中点另需灯光遮挡射线。
首次更新所有层级的 8192 个探针，初始化开销单独测量，不等于稳定帧预算。
射线长度随该级间距变化（间距的 16 倍），避免远级仍只查询近处遮挡。

### 小型自发光与近场照明

参与 TLAS 的发光网格在帧槽内列出三角形，不把它们改成点光源。GPU 每帧先将各三角形
等分为四个子三角形，保存世界坐标和中心 UV 处的线性自发光颜色；随后复用预处理结果。
预处理同时保存原三角形的包围球；近场查询先剔除完全超出 8 米或位于接收面背后的三角形，
通过测试的三角形才执行四个子样本。这是保守剔除，不减少相关样本或改变光源亮度。
近场查询复用与现有四级 DDGI 覆盖对齐的空间分块候选缓存：每级 16×8×16 个单元，
每个 RGBA32Uint 像素保存 128 个发光子样本的候选位。GPU 保守筛选距单元包围盒八米内的
样本，包围盒包含射线原点偏移。查询选择包含接收点的最细一级，只遍历置位样本，保留原有
积分顺序与实时遮挡检查；四级之外仍完整查询，不因缓存覆盖而丢光。
每个帧槽只在覆盖原点、发光网格/变换或列表发生变化时重建；候选生成不按颜色过滤，材质
或纹理亮度变化仍从当帧预处理结果读取。移动遮挡物不影响空间候选，遮挡射线每次照常查询。
候选缓存不存最终亮度，因此能跨帧复用，也能用于 MSAA 边缘的独立表面查询。
这借鉴了 [Lumen 的共享计算与跨帧复用思路](https://www.unrealengine.com/tech-blog/unreal-engine-5-goes-all-in-on-dynamic-global-illumination-with-lumen)，
并不是 Lumen 的完整辐亮度缓存或重要性采样。生成后通过显式屏障供查询读取；资源由帧槽拥有。
每个子三角形以精确立体角乘中心方向余弦近似辐照度，并向中心发射遮挡射线。
采样点固定在几何上，几何、材质或遮挡改变时重新计算，不冻结旧画面；小 LED 不再因
每帧旋转的 64 条球面射线漏采而突然熄灭。镜像实例保留材质法线的朝向。

仅靠 4 米探针不能表达 LED 与接收面之间不足一格的空间，因此自发光积分分为近场与远场：
子三角形中心距接收点 4 米内由半分辨率表面查询直接计算，4～8 米用 smoothstep 将权重
逐渐交给探针；8 米以外由探针提供。两条路径使用互补权重，球面射线不再计入同一份发光能量。
表面查询在深度/法线边缘仍沿用几何拒绝，无法复用邻域时对当前表面直接查询。
距离权重分别在接收面和探针位置计算，远场仍有探针插值误差，不保证解析面积光精度。

这是有遮挡的面积光积分近似：每个子三角形只检查中心射线与纹理，部分遮挡边界或高频发光
纹理仍会受四点采样精度限制。源三角形数量增加时，射线、近场查询和初始化开销相应增加；
没有发光面的场景不执行这些积分。每帧预处理、射线图片与发光索引表由帧槽拥有；稳定阶段
射线图片只保留该帧更新批次需要的高度，首次初始化使用完整探针数。

每个探针以 6×6 八面体方向纹理保存辐照度和距离一、二阶矩，外加一圈镜像边界用于双线性采样。
四级打包进两组 512×1024 RGBA32F 历史附件，由 `Ddgi` 跨帧拥有；每个帧槽有独立射线附件、geometry 表与 UBO。
更新与采样在同一队列显式排序，不因窗口 resize 重建固定尺寸探针图。

半分辨率通道复用阴影表面的位置和几何法线，读取邻近 8 个探针，结合三线性、法线朝向和距离矩可见度权重。
主材质按位置和法线边界重建间接光，再乘底色与非金属比例；没有有效邻近样本的细小边缘直接查询探针。
间接光方向使用几何法线，法线贴图仍影响原有直接光。半分辨率结果由帧槽拥有，resize 时只需等待该槽 fence。
超过四分之一射线命中背面的探针视为位于几何内部，不参与照明；尚未实现探针重定位。
按近到远顺序选择覆盖当前位置的层级，边缘一格使用 smoothstep 平滑过渡到下一层，不叠加重复能量。
每级按自己的间距滚动，只复用该层中世界位置相同的历史；新区域在分帧填充前可使用更远一级。
探针 alpha 区分未初始化（-1）、位于几何内部（0）和有效（1）：已分类的暗区不因没有有效探针而改用远级照明。
最外层仍有有限范围，边缘渐隐；这是局部多级覆盖，不是无限世界的 GI。
历史保留权重为 0.5，快速昼夜、移动光源和遮挡变化仍有延迟；薄墙、小房间、稀疏探针及
体积外区域仍有限制，不能当作无漏光或全大陆 GI。没有探针重定位或自适应更新。

资源准备位于材质上传和 TLAS 准备之后、HDR 光照之前；契约见 [渲染图](render-graph.md)。
`lc1_pbr_tests` 在实际 GPU 上检查天空能量、双帧槽、滚动、自发光/太阳反弹、遮挡及关闭/重新启用，
还检查原 30 米边界至 800 米处的受光、各层边界及跨层滚动，输出 DDGI 开关和零天空的场景对照，并用 GPU timestamp 分别记录初始化与稳定帧耗时。
运行命令见上文。编译、验证层、GPU 数值和实窗观感分别验收，未测量时不承诺毫秒预算。

## 地表细节

`ContinentView` 拥有三张 256² 无缝程序贴图：sRGB 草土色调颗粒、线性 MR 和线性法线。
地面和道路在同一网格中混合颜色，共享每四米平铺的材质，粗糙度在 0.84～0.98 之间变化；法线由毫米级高度噪声差分得到，
与底色颗粒共享噪声。世界坐标 UV 保持跨地形格和分块连续，上传前生成 MikkTSpace 切线。
路沿过渡与噪声规则见[世界地图](world-map.md)。原有棋盘明暗替换为世界坐标连续色差；建筑使用独立的原始材质，不接收地表贴图。
这些细节不增加几何起伏，不改变碰撞；DDGI 继续使用几何法线计算间接光。

## 火把

WorldPresentation 按装备状态为存活角色生成世界空间火焰粒子，位置跟随手部挂点，木柄保持世界竖直方向。
每支每秒产生 50 个粒子，每十二个中有一个火星；火焰寿命 0.38～0.63 秒，火星 0.8～1.5 秒。
粒子保留出生时的世界坐标并向上运动，因此移动时留下短拖曳；火焰逐渐收缩、变红和消散。
停顿后只补生成最近一秒内仍存活的粒子，不积压旧粒子。卸下或死亡时立即清除，不改变模拟或存档状态。

Scene::Particle 是独立于不透明 mesh 的值记录，在入口校验尺寸、颜色、透明度和有限数值；帧注册复制粒子列表。
Renderer 在同一 HDR 渲染实例的不透明物体和世界文字之后，按相机空间深度从后到前绘制面向相机的六顶点贴片。
程序 shader 生成软边和上窄下宽轮廓，无贴图依赖；使用直线 alpha 混合，开启深度测试但关闭深度写入。
粒子不参与阴影、TLAS 或 DDGI，不会遮住自身灯光；这是火焰/火星特效路径，不是任意相交透明物体的完整排序解法。
同一角色的手电筒与火把共用一个 SceneLight，火把使用暖色 SphereLight，半径 0.08 米、每帧两条阴影射线，
亮度由连续正弦叠加轻微调制。F4 的 All / Sphere 模式启用照明；Emission Only 仍显示火焰自身。
不启用自发光 GI；环境照明和反弹来自显式球形光。粒子不受展品暂停开关影响。

## Bloom

OutputSettings::bloom_strength 默认为零，独立材质测试和工具不改变输出；主场景启用 0.12。
HDR resolve 后以半分辨率提取高亮，线性 HDR 1 附近使用软阈值，再进行横向、纵向 Gaussian 模糊。
两张 RGBA16F 图片及 heap 索引由帧槽持有，在该槽 fence 完成后重用/resize；每阶段显式同步写入与读取。
Bloom 在色调映射前加回颜色，不修改原始 HDR 图，不影响 UI；关闭时跳过通道和图片分配。
采样使用 clamp-to-edge 和线性过滤，奇数尺寸及 1×1 输出均支持。它是屏幕空间光晕，不替代照明或体积散射。

GPU 专项：`./lc1_pbr_tests --particles` 检查透明混合、顺序、遮挡、1×/4× MSAA、双帧槽和 Bloom resize；
`./lc1_pbr_tests --torch` 同时验证火把装配，输出 `artifacts/torch.ppm`。实机结果需与编译、CPU 测试分开记录。
