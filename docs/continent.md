# 大陆与城池空间设计

## 已确定的体验（2026-09-29）

- 城内、城外和战斗保持同一种视角，玩家通过 WASD 移动。
- 城池是大型可游玩的空间，玩家能够穿过城门、走入街道、接近建筑，并在其中战斗。
- 角色、城池、野外使用一致的空间尺度，进入城池不发生战略地图到战场的比例变化。
- 城池的生产、建设、部署与战斗共用同一份持久状态。

镜头当前按用户要求采用类似《饥荒》／《红警》的固定斜俯视。是否无缝加载、
世界和城池的最终尺寸尚未确定；
统一视角本身不要求整片大陆同时驻留内存。

## 建议的职责

`Continent` 表达大陆的地理和空间布局，提供范围、地形、地点与空间查询。
地形绘制由单独的显示部分负责，接入现有 `GpuMesh`、`Material` 和 `DrawItem`。
玩家控制器读取输入并产生动作意图；角色决定速度，物理组件通过 `WorldCollision` 查询碰撞并计算移动，
分工见[角色物理](physics.md)。相机按照统一规则观察玩家。

第一版可以先保留少量地形和静态物体。地图范围不再由一张图片的像素大小决定，
贴图、导航数据与可行走地面都必须映射到约定好的世界坐标。

### 地形区块

将大陆按空间划分为区块。每个区块描述这一片的地形、静态物体放置和通行数据；
运行时逐步支持加载玩家附近的区块、显示远处的简化内容。

区块大小、加载半径和细节层次属于后续可调的实现参数。原型阶段可以把少量区块全部加载，
先验证移动、碰撞和空间尺度，再实现异步加载与卸载。

一座城可以跨多个区块；城池边界与加载边界分别表达玩法区域和空间管理单位。
跨区块的城墙、建筑等实体保留一个身份，各区块的空间索引可以引用它，不能生成多份状态。

### 城池空间与城池状态

城池的空间描述需要包含占地区域、入口、街道和建筑布局，不能仅用一个入口坐标表达整座城。

城市归属、资源、建筑等级和耐久、驻军等由游戏状态持有。经济与战斗系统访问同一份数据：
同一段城墙既是建设成果，也是战斗中的防御设施；士兵进入战斗后继续使用自己的装备。
卸载城池的显示内容不应丢失这些状态，也不意味着远处的经济模拟自动停止。

## 坐标与尺度建议

沿用项目的右手系、Y 向上，地面坐标使用 XZ。建议以 1 游戏单位约等于 1 米为原型约定，
用角色身高、移动速度、门洞和街道宽度共同验证尺度，再决定城市尺寸和旅行距离。

地形区块可以使用局部坐标，区块原点负责换算到大陆坐标。建筑和角色的位置最终落到同一套
空间关系中。超大世界的精度问题在世界范围确定后处理，暂不引入浮动原点等额外机制。

现有大陆图片可继续作为布局参考和原型背景。实际地面需要逐步补充地形几何、地表材质与碰撞；
图片中的城市图案不等同于已经建好的可行走城池。

## 移动与寻路

WASD 产生期望移动方向，控制器通过碰撞检测、滑动和地面高度查询得到可到达的位置。
玩家按键移动无需每帧运行 A*。

NPC、军队和自动移动功能使用导航数据规划路径，再通过移动控制器执行。
第一版单层地面可以使用网格；桥梁、城墙步道、楼层等叠层空间将需要多层连接或导航网格等
更丰富的表达，不能把整个世界永久限定为每个 XZ 坐标只有一个可行走高度。

城门开闭、建筑损坏等改变通行条件时，更新受影响的局部导航数据。寻路也需支持跨区块连接。

## 第一段原型

先做一段城外道路、一扇城门和一段城内街道，用简化几何验证：

1. 玩家通过 WASD 从城外走进城内，镜头和控制方式保持一致。
2. 地面可行走，城墙与建筑能够阻挡移动，门洞可以通过。
3. 建筑与角色的尺寸、道路宽度和行走时间符合预期。
4. 一名 NPC 能沿路径穿过城门；关门后不能继续沿原路径穿墙。

这些成立后再扩展城池面积、建筑数量、地形区块加载和大部队战斗。

## 当前实现

- `Continent` 接受 `ContinentData`，由 `Region`、`Location`、`Road` 组织世界；
  格子按 `tiles[z][x]` 排列并引用区域 ID，查询统一转换世界坐标。海域和山地阻挡步行。
- 默认大陆按现世地图轮廓生成，范围为 6144×4096 米，每格 16 米；城池占地 320×384 米，有城墙、门楼、
  主街、横街、广场和 32 栋简化民居，以及街道尽头的一座大型建筑。
- 当前大陆有平原和海域，以及城池、村庄和海岸三个地点；导出流程见 [现世大陆轮廓接入](continent-outline.md)。
  原有五类区域、六类地点和五条道路的小样例保留用于测试，数据关系见 [世界地图结构](world-map.md)。
- `ContinentView` 将大陆分为 384 个 256 米区块，各区块按地形、结构和草丛分组生成网格；地形使用高度场角点插值，
  渲染顶点高度与角色查询共用同一份 `terrain_sample()`；道路直接混入地形颜色，
  过渡规则见[世界地图](world-map.md)。建筑显示和碰撞共用
  包围盒。所有区块目前一次性加载，尚无流式加载和远景细节层次。
- `Character` 使用直立方形截面的身体，半宽 0.3 米、身高 1.8 米、眼高 1.65 米；
  步行 4.5 米/秒，跑步 9 米/秒。连续扫掠避免越过薄墙，接触后沿墙滑动。
- 当前由 `lc1::PlayerView` 管理视角，默认采用斜俯视模式，使用固定斜俯视的透视相机并跟随玩家，
  城内外共用 `Gameplay` 输入上下文。WASD／方向键按画面方向移动，Shift 跑步，
  鼠标可见，滚轮缩放，Esc 退出。M 在斜俯视和第一人称之间切换，初始为前者；第一人称捕获鼠标用于转向，切回时释放鼠标并回到玩家。
  两种视角共享玩家位置和碰撞，斜俯视缩放及 Y 锁定状态保留，无自由飞行按键。
  按 2026-09-30 的用户决定恢复透视投影，物体呈现近大远小。
  垂直视场角固定为 45°，滚轮累计修改目标缩放，相机使用与 Space 回中相同的插值速度
  沿视线平滑推近／拉远；停止滚动后继续收敛，零帧时间不推进过渡。推屏速度按当前显示尺度计算。
  移动和缩放都不改变镜头朝向。
  注视点深度处、垂直于视线的平面上，默认纵向可见 48 米，可缩放到 16—96 米，
  对应相机到注视点约 58 米、范围约 19—116 米；这不表示所有深度的可见范围相同。
  默认锁定角色，Y 切换锁定。未锁定时角色移动不带动镜头，鼠标接近窗口内容区域边缘可推屏；
  空格回到角色位置，按住可临时跟随，松开后保持未锁定。锁定时不响应边缘推屏。
  推屏使用窗口逻辑坐标，边缘感应带为 24 点，速度随缩放调整；镜头中心限制在大陆范围内。
  鼠标离开窗口、窗口失焦或 UI 接管时停止推屏；复位优先于同一帧的边缘输入。
  蓝色身体、金色头部的占位模型表示玩家；模型和场景资源由 `lc1::WorldPresentation` 持有。
- 网格顶点绕序统一朝外；渲染器根据模型矩阵行列式自动调整正面绕序，保留背面剔除。

运行 `make run`，出生点在城门外 32 米处，向南沿路可穿过村庄到达南湾海岸。
窗口标题显示角色当前区域及地点／道路名称。地形与道路使用程序生成的无缝底色、粗糙度及法线贴图，每四米重复一次，
地图色调由顶点提供，并叠加世界坐标连续的缓慢色差；建筑仍使用 `textures/prototype-white.png`。
法线细节只影响着色，不改变高度与碰撞；大陆图片对应 SVG 的海陆轮廓已离线导出为地形格。
运行资源位于未入库的 `runtime/assets/`，完整准备要求见[构建指南](../BUILD.zh-cn.md)。

当前默认大陆加入了高度场起伏，出生点东侧有一座可直接步行攀爬的缓坡，远处还有若干
山丘；角色通过 `WorldCollision` 的支撑面查询跟随地形高度。出生点东南侧还放置了一座方形螺旋
楼梯塔：中央是 4×4 米石柱，楼梯绕柱一周上升 9.6 米；每跑 8 级、踏步高 0.3 米、
踏面深 0.5 米，共两圈。西南角同一 XZ 位置同时存在地面、9.6 米中层平台和 19.2 米
顶层平台三个可行走支撑面，上下两圈的楼梯踏面也会在不同高度重叠。建筑仍为封闭体块，
门窗标记仅作外观，尚未实现建筑内部、楼层导航、NPC 寻路、可开闭城门、经济／驻军状态
和城市状态存档；角色与队伍进度已有[本地存档](save-data.md)。城池本身与连接道路保持平地，便于继续验证比例和移动。

验证命令：

```bash
cmake --build --preset linux-x86_64-debug -j 8
ctest --test-dir build/linux-x86_64/Debug --output-on-failure
```

CPU 测试涵盖格子边界、海岸阻挡、薄墙高速碰撞、滑动、转角、门洞净高、城门双向通行、
斜向速度和随机移动后的无穿透约束，以及透视近大远小、深度范围、滚轮距离缩放、
镜头锁定切换、临时复位、边缘推屏和失焦／UI 门控。
新增世界地图测试覆盖区域归属、地点／道路身份与查询、无效布局拒绝、地点网络连通性和道路双向步行。
Vulkan 绘制另通过 Debug 验证层运行检查。

## 可进入的巡逻房屋

现世地图出生点东侧新增 `Patrol House`，位于 X=28～50、Z=14～42，
西侧入口中心为 (28,34)，从出生点沿路向南到 Z=56 后向东绕开展示台，再沿房屋西侧向北即可到达。
房屋使用同一世界坐标和碰撞数据，不切换场景。
三层地板高度为 0.6、4.2、7.8 米，底层另有 1.2 米的抬高平台。
房间包含隔墙与门洞，两段各十二级的楼梯连接不同楼层；楼板为楼梯井保留开口。
楼梯顶端与楼板共用精确的连接高度，避免浮点差造成无法下楼的小台阶。
为观察室内，房屋采用开顶剖面，东／南侧为低墙；可切第一人称走入，不代表完整屋顶遮挡系统。

几何与往返巡逻折线集中定义于 `game/continent/patrol-house.*`。
现世地图沿用 `session.example` 的 NPC：新种子世界在房内生成，沿平台、楼梯、上层房间和门外道路往返，
顶层停留两秒。读档保留位置，按距当前位置最近的三维路点接回路线；
已停止的巡逻和 Follow／Wait 命令不被覆盖。旧测试大陆保留原巡逻。
这是手工指定的可通行路线，尚不提供任意室内位置的自动寻路或动态障碍重规划。

CPU 测试用实际角色碰撞完成上楼、下楼、错层平台、出入房屋及高层存档恢复后的往返巡逻，
并检查墙壁、门洞净空和同一 XZ 下的多层空间；渲染与窗口运行需单独验证。

## 地表装饰

现世大陆的 PBR 材质展区位于出生点正西 120 米，仅作为材质展示，不占用出生点附近的主要活动区。
原型测试大陆保留原展区位置，以便继续使用固定视角的 GPU 截图测试。

`ContinentView` 在自然地表全域生成草丛，道路两侧约十米范围加密，并生成稀疏碎石。少量 8～18 厘米矮草伸入土路边缘，
中央通行区域保持干净。位置和尺寸由世界坐标确定，重载保持一致；道路交叉口的中央、地点范围、
非草地铺装、建筑附近、海域和陡坡不放置。草叶使用窄幅弯折的双面实体三角形，
石块是部分埋入地面的低面数几何，均参与原有直接光阴影和 DDGI。
它们是静态装饰，不增加碰撞，也没有风动画。

调试面板的 `Grass density` 滑条范围为 0～200%，每档 25%，默认 100%。
路边草丛以 0.6 米世界坐标网格抖动采样，每丛七片草叶；其他自然地表使用 12 米网格、每丛三片草叶，
避免在当前全图常驻方案下生成过多几何。斑块噪声及路边外缘渐稀形成自然分布。
草丛在整个常驻场景预生成八个密度组，拖动只改变组的可见性，不重建 GPU 资源；已有草的位置不变，碎石不受影响。
隐藏组仍计入帧资源容量，调节后无需扩容。设置只在当前会话有效，不写入存档。
碎石合并进各区块结构网格，草丛按密度组合批并共享材质，不逐株创建对象。
没有新增流式加载或远景细节层次。

## 南田村口与铁匠铺

南田村口采用错落的木骨灰泥住宅、石基和交错屋脊朝向的双坡屋顶，
住宅高度、进深和离道路距离各不相同。开放式铁匠铺位于主路西侧，
住宅、作坊、集市和后方钟楼共同围出街道与小院；柴堆、水桶、砧台、
工作台、废铁、货摊、手推车与菜地按使用位置布置。
这些仍是程序生成的原型几何，门窗不是可交互室内入口。

村内通路直接使用 `Road` 折线与不同路宽，沿用地形融合、碰撞净空和
图连通校验，不使用矩形道路 patch。主路有连续转折，作坊入口较宽，
集市支路和通往钟楼的小径逐渐收窄。城内既有铺装不属于此次村口重建。
`BlockShape::GableX/GableZ` 生成真实双坡屋顶轮廓，碰撞保留保守包围盒；
坡屋顶不作为可行走支撑面，跨显示区块时由起点所在区块完整生成一次。

共享地标定义在 `game/continent/village.hpp`，炉床、暖色面光源和火焰粒子
共用炉火坐标；没有新增独立火焰渲染路径。接近村庄时直接光减弱并偏冷，
天空漫射增强，保留昼夜变化；离开村庄平滑恢复原有光照。
烟雾和环境音见下文；远景空气透视使用[距离雾](lighting.md#远景距离雾)。

`lc1_pbr_tests --village` 输出村口眼高、斜俯视和作坊近景三张 GPU 截图到构建目录的
`artifacts/village-0.ppm`、`artifacts/village-1.ppm`、`artifacts/village-2.ppm`，并打印该视角的 GPU 帧时间。
CPU 世界地图测试逐段验证弯道的双向全宽通行，检查村内没有道路 patch。

临街长立面补有木骨分格、上下层窗洞、窗板与门楣，石基使用错缝凸出的石块。
住宅院落、旅店后院与菜地以低木篱笆分界，作坊旁有雨棚柴堆与淬火桶，
市场边增加带卷轴和水桶的石井。木桶、圆木与车轮使用十二边形圆柱轮廓，
三种圆柱轴向由 `BlockShape::CylinderX/Y/Z` 显式指定；可见轮廓仍按原包围盒碰撞，
不作为可行走支撑面。它们与建筑合批，不增加逐物件 draw。

作坊烟囱使用少量透明灰烟粒子，与炉火共享排序透明通道，烟雾不充当光源。
风声、锤击与钟声由 `scripts/generate-village-audio.py` 离线生成原创占位 WAV，
运行时由 `WorldPresentation` 持有三个循环 OpenAL 声源；锤击与钟声定位于作坊、钟楼，
风声跟随听者，离开村庄平滑静音，沿用主音量控制。锤击、钟声的参考衰减距离
分别为 8 米、18 米，兼顾斜俯视相机高度与近距离观察。
当前声音是合成占位素材，未加入人声交谈；60 米外逐渐加入冷灰距离雾，190 米处半隐，320 米外融入雾色；天空保持独立，为后续云层保留绘制空间。
