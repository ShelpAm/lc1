# 世界地图结构

世界地图继续由 `Continent` 持有，使用统一的斜俯视透视镜头和 XZ 地面坐标。
本次实现的是地理、地点与道路的静态空间骨架；不会因进入城市而切换地图比例。

```text
世界地图 Continent
├── 区域 Region
│   ├── 平原 Plain
│   ├── 森林 Forest
│   ├── 山地 Mountain
│   ├── 荒原 Wasteland
│   └── 海域 Sea
├── 地点 Location
│   ├── 城市 City
│   ├── 村庄 Village
│   ├── 要塞 Fortress
│   ├── 港口 Port
│   ├── 遗迹 Ruins
│   └── 野外地点 Wilderness
└── 道路 Road
    ├── 连接的地点 from / to
    ├── 中心折线 points
    └── 路宽 width
```

## 数据关系

`RegionId`、`LocationId`、`RoadId` 是不同类型的稳定编号，不是数组下标。
同类编号必须唯一且非零；重排数组不会改变引用关系。名称用于显示，不承担身份。

每个地形格子的 `TileData::region` 引用一个区域。区域记录名称和地形类型，
因此多片森林可以有各自的名称和编号；格子不再重复保存一份可能与区域冲突的地形类型。
区域边界由格子归属决定，可组成不规则形状。当前平原、森林、荒原可以步行，
海域、山地阻挡步行；树干与建筑还会进一步限制通行。

地点保存类型、占地矩形 `bounds`、入口 `entrance` 和入口所属的区域 `region`。
一座城可跨多个区域和显示区块，`region` 不限制整个地点的面积。
入口允许位于占地边缘，但必须在世界内并能容纳玩家。
原来的 `CityLayout` 已统一为 `LocationType::City` 的地点。

道路是两个不同地点之间的双向连接，至少有两个折线点，首尾严格对应两端的入口。
宽度以米计，支持斜线和转弯，端部与弯角按圆形连接。
地点之间可以有多条道路；`roads_from` 查询双向邻接，不执行 NPC 寻路。
只有共享地点端点的道路才在图中相连，几何相交不会自动生成新的图节点。
道路跨过区域时不改变区域身份，也不把水面或山地变成可行走地面。

城市归属、资源、驻军、城墙耐久仍留给后续持久状态，以地点 ID 关联。
经济建设与战斗部署共用这些状态；本次没有添加两套城市系统。

## 查询与校验

- `region / location / road` 按 ID 查找，`regions / locations / roads` 提供只读集合。
- `region_at / location_at / road_at` 按世界 XZ 坐标查找，未命中返回空指针；返回值借用地图存储。
- 地点占地查询使用左闭右开边界；嵌套地点选择面积最小者，相同面积按定义顺序。
- 道路相交处的 `road_at` 返回第一条命中的道路；`Road::length` 返回折线总长，
  `Road::contains` 可加净空，用于放置路边物体。

地图构造时检查编号、引用、地点范围、入口净空、道路首尾、宽度和退化线段。
道路以半路宽的方形截面连续扫掠，保证整个宽度有地面且没有建筑阻挡；
这是保守校验，在狭窄斜向通道中可能要求比可见路面更大的净空。
桥梁、隧道和航线需独立扩展通行层，目前不能把一条道路直接画过海域。

## 当前游戏地图

默认种子存档选择 `present` version 1，由 `Continent::load()` 解析并调用 `Continent::make_present()`，按现世地图生成 6144×4096 米大陆与群岛。
每格 16 米，显示分为 384 个 256 米区块；北为 −Z，东为 +X，所有区块一次性加载。
当前只接入海陆，城池、村庄、海岸通过两条道路连接；具体坐标、生成与验证流程见
[现世大陆轮廓接入](continent-outline.md)。

## 保留的全类型测试样例

`Continent::make_prototype()` 保留原有区域和地点组合，用于回归测试。
范围为 X = −384～384、Z = −576～320 米，每格 16 米。

| 区域 | 位置与外观 |
|---|---|
| 长风平原 | 世界中部，绿色地面 |
| 东境森林 | 东部，深绿地面、带碰撞的树木 |
| 北境山脉 | 北部，灰色地面、岩山体块，禁止步行 |
| 赤土荒原 | 东南部，黄褐色地面 |
| 西海 | 西侧，蓝色水面，禁止步行 |

| 地点 | 类型 | 入口 XZ | 简化空间 |
|---|---|---|---|
| 长风城 | 城市 | (0, 0) | 原有 320×384 米城池、城门、街道、民居 |
| 南田村 | 村庄 | (0, 112) | 村屋、中央道路和田地 |
| 北山要塞 | 要塞 | (−208, −400) | 山脚围墙、门洞和塔楼 |
| 西岸港 | 港口 | (−240, 96) | 仓库、木质岸边平台、货箱 |
| 赤土遗迹 | 遗迹 | (112, 224) | 石基、断柱和残墙 |
| 林边营地 | 野外地点 | (224, 64) | 帐篷占位体块、营火基座和物资 |

```text
长风城 ──城南大道── 南田村 ──西港商路── 西岸港 ──北山军道── 北山要塞
                      ├──林间小径── 林边营地
                      └──荒原古道── 赤土遗迹
```

城南大道宽 8 米，西港商路和北山军道宽 6 米，两条支路宽 4 米。
原有城内街巷仍由地表铺装描述；跨地点道路从 `Road` 生成，不再另写一份道路色块。
路面按区块边界裁切，绘制时跟随地形高度并抬高 2 厘米作为近景保护；道路同时拆成独立
draw，使用负深度偏移解决远距离与地形的共面冲突，并关闭投影。角色碰撞仍使用同一份地形
高度采样。

旧样例的出生点为城门南侧道路的 (0,32)，村庄向西连接港口及北山要塞，
向东连接营地，向东南连接遗迹。默认游戏使用上文的新大陆。
WASD／方向键移动、Shift 跑步、滚轮缩放、Y 解锁镜头推屏、空格回到角色、Esc 退出。
窗口标题和终端日志显示角色当前区域，以及地点或道路名称；自由镜头推屏不改变角色所在地点。

## 验证与后续

`world_map` 测试覆盖稳定 ID、空间边界、折线宽度、双向邻接、无效引用、
穿海／穿墙道路拒绝、全类型样例、全地点连通性及每段道路双向步行。
原有 `continent` 测试继续覆盖城门、碰撞、玩家移动和镜头控制。

```bash
cmake --preset linux-x86_64-debug
cmake --build --preset linux-x86_64-debug -j 8
ctest --test-dir build/linux-x86_64/Debug --output-on-failure
```

样例布局在 `src/game/continent/prototype.cpp`，类型和查询接口在
`include/lc1/game/continent/continent.hpp`，地图校验在 `src/game/continent/continent.cpp`，碰撞查询与扫掠在
`src/game/physics/world-collision.cpp`，角色运动见[角色物理](physics.md)，
显示在 `src/game/continent/view.cpp`。新增地点时分配 ID、设置范围与入口、
放置几何，再按入口连接道路；场景与碰撞会共同验证路线。

当前默认大陆已有基础高度场起伏和可攀爬缓坡，但仍是体块原型，未实现地点交互、
自动寻路、资源产出、海上航行、桥梁或区块流式加载。现世出生点东侧已有带多层空间与 NPC 巡逻的
可进入样例房屋，见[大陆设计](continent.md#可进入的巡逻房屋)；大陆几何本身尚不写入存档。

大陆自身持有稳定标识和内容版本；存档选择与兼容规则见[存档与继续游戏](save-data.md#大陆选择与内容版本)。
