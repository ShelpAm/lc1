# 博宇大陆 · 现世形势图

当前游戏轮廓采用 `continent-present.svg`，对应 `runtime/assets/unused/textures/continent-present.png`。
运行 `python3 docs/map/export_continent.py` 导出海陆格，`--check` 检查生成数据是否过期；
完整流程见 [现世大陆轮廓接入](../continent-outline.md)。
下文介绍的是较早的 `world-map.svg` 设定图，其地名和区域布局与当前现世图不完全相同。

按世界观草案画的「现在」的大陆形势图。`docs/content.md` 里三个模块中的「地图」，这是它第一版的样子。

| 文件 | 说明 |
|---|---|
| `world-map.svg` | 矢量图，可直接编辑、无损缩放 |
| `world-map.png` | 3300×2250 位图，方便看 |
| `generate_map.py` | 生成脚本，改表即改图（纯标准库） |

重新生成：

```bash
python3 docs/map/generate_map.py
magick -density 144 -background none docs/map/world-map.svg docs/map/world-map.png
```

PNG 依赖 ImageMagick 的 librsvg 后端，字体用 Noto Serif CJK SC。图上的地理要素全部来自
`generate_map.py` 里的几张表（`LAND_CONTROL` / `EMPIRE_REGION` / `TRIBE_*` / `CREST` /
`RIVERS` / `CITIES` / `ROADS` / `MYSTERY` …），改坐标或改名字后重跑即可；随机抖动用固定
种子，所以同样的输入永远得到同一张图。

## 世界观 → 地理

| 世界观里的条目 | 图上落成什么 |
|---|---|
| 帝国：人类为首，占据大陆大部分地区 | **曜帝国**，大陆中部与东部的大河平原，图上最大的一块 |
| 部落：退守森林、山脉、荒原以及群岛 | **沉语森林**（西）、**铁脊山脉 / 北岭**（北）、**赤砂荒原**（南）、**碎星群岛**（东北，地图边缘） |
| 11战争 | **灰烬防线**：贯穿中南部的旧战线，现在是帝国与荒原部落的争议地带 |
| 星尘力量枯竭 | **星陨湖**与**星尘滩**：大陆最大的星尘汇聚地，被帝国抽干，只剩盐滩和湖底遗迹 |
| 神秘种遗迹散布各地 | 图上五处，带金光的两处仍有星尘残留，另三处已枯 |
| 帝国转以机械、炼金、冶炼立国 | **铁炉城**（山麓冶炼重镇）、沿河的田畴带、辐射状驿道网 |

## 待确认

1. **名字全是新拟的**，语感偏中文奇幻。想换风格（更欧洲、更冷硬…）直接改表里的字符串就行。
2. **纪年空着**：世界观没给「11战争」的年份与停战年数，图上只写「停战之后」，没有具体数字。
3. **部落只分了四支**（北岭、沉语、赤砂、碎星）。原案说类人种「种类繁多」，需要的话可以再拆细。
4. **灰烬防线是新增设定**：给「部分部落仍与帝国存在领土和资源冲突」一个具体位置。
5. **星陨湖 / 星尘滩也是新增的**：给「星尘枯竭」一个看得见的地点，顺便解释帝国的星尘从哪来、又去了哪。
