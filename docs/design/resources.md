# 资源

## 当前铁盔打造契约

`resources/recipe.hpp` 的 `Recipe` 拥有输入与输出堆叠列表，借用只读资源定义；
`can_craft` / `craft` 负责检查与执行。铁盔配方位于 `resources/crafting.hpp`：
生铁 5、木材 2、Moneta 20 → 铁盔 1。该配方使用进程期只读定义，不依赖铁匠背包中的零数量占位。

`Bag` 使用私有堆叠与总容量计数，只通过 `add`、`remove`、`quantity_of` 操作；`add` 和 `remove` 接收只读资源引用，加入的资源定义必须比背包长寿；
构造时指定重量上限，单位克；角色默认 10000 克，每单位资源使用目录中的克重。移除数量为零时直接成功且不改变背包，无需已有对应堆叠；移除到零时删除堆叠。
打造在候选背包中先扣材料再添加产出，成功后同时提交堆叠与容量计数。
材料不足、产出超容量、数量溢出或分配失败均不改变原背包；满包在扣料腾出空间后仍可打造。
背包容量和资源编号、数量通过 [checkpoint](../save-data.md) 保存恢复，资源定义仍来自目录。
装备行为保持原有约定；本节之外为玩法设计。

## 资源系统

资源系统分为以下几个模块：
- 资源产出：资源出现方式
- 资源流通（交易等）
- 资源消耗：资源完全消失的方式

模板
```
- 产出：暂无
- 流通：暂无
- 消耗：暂无
```

资源分为以下几个类型：

### 莫那塔（货币）
基本的交易媒介，主要用于购买物品、服务等。

- 产出：暂无
- 流通：探索，完成任务的奖励，交易，购买/出售 物品、服务
- 消耗：暂无

- 包装：称作 moneta，莫那塔。

  > Moneta 源自拉丁语 *monēta*，意为“货币、铸币”，也是英语 money 与 monetary 的词源之一。

### 木材 (Wood)
用于装备铸造及其他。

- 产出：砍伐树木
- 流通：野外探索，任务奖励，交易
- 消耗：烧炼

### 生铁 (PigIron)
用于装备铸造及其他。

- 产出：开采矿物，熔炼物品
- 流通：野外探索，任务奖励，交易
- 消耗：打造装备

## 资源字段

基础资源包含以下字段：

enum ResourceType {
  Moneta,
  Wood,
  PigIron
};

enum ResourceCategory {
  Currency,
  Material
};

BasicResource:
- ResourceType type 资源类型，如莫那塔，木材等
- ResourceCategory category
